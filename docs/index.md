# CNC Tracker - Project Documentation

Welcome to the comprehensive documentation for the CNC Tracker project. This index serves as the primary navigation hub for developers and AI agents.

## Project Summary

CNC Tracker is a specialized management system for customs, insurance, and logistics operations. It features a React-based frontend and an Express-based backend with deep AI integration.

### Quick Reference
- **Type:** Multi-part Monolith
- **Architecture:** Layered (Backend) / Component-based (Frontend)
- **Primary Tech:** Typescript, React, Express, PostgreSQL (Drizzle)
- **Deployment:** Hetzner VPS / PM2
